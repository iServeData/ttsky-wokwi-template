# Security

## Reporting a problem

Please don't open a public issue for a security problem. Use GitHub's **Report a vulnerability**
(Security tab → Advisories) on this repository. Include what you found and how to reproduce it.

## Scope

This is a hardware design project; the only automation is the GitHub Actions workflows, which use pinned actions and no secrets beyond `PRIVATE_TERMS` for the sanitizer.

## Supported versions

Only the latest version on `main` gets fixes.
